BIM VIEWER PRO -- HELP & GUIDE
BIM VIEWER PRO 4D / 5D

Real-time 3D/4D/5D construction twin viewer. Load IFC models, inspect elements, simulate construction timelines, and estimate project costs all in the browser.

QUICK START -- 5 CORE STEPS
01
Load a Model
Click Load Sample in the Files panel (Key 1) or upload your own .ifc or .frag file. The model loads with full element classification and twin data.
02
Inspect Elements
Double-click any 3D element to open the Properties panel (Key 5). See IFC type, name, storey, category, 4D task dates, and live 5D cost fields.
03
Navigate the Model
Orbit by dragging, Zoom with scroll, Pan with right-click drag. Switch to First Person mode (Key 6) to walk through the building with stair-climbing physics.
04
Simulate 4D Construction
Press ACTIVATE 4D in the header. Drag the timeline scrubber to simulate the build sequence. Use speed pills 1x 2x 5x 10x to control playback rate.
05
Estimate 5D Project Cost
Select an element, open 5 INSPECT panel, enter Unit Cost and Quantity. The calculated cost and project grand total update live across all elements.
SPECIALIZED TOOLS
📐
Tape Measure
Enable in the 7 TOOLS tab. Click two points in the 3D viewport to measure real-world distance. Results appear as 3D annotations on the model.
✂️
Section Cut
Click Section Cut in the bottom toolbar, then double-click the viewport to place a cutting plane. Reveal interior structure at any angle.
🔍
Items Finder
Key 2. Search and filter by Category or Storey. Click any filter chip to isolate elements.
🏗️
4D Timeline
Activate 4D mode from the header. Elements appear, progress, and complete according to their scheduled dates. Use speed pills 1x to 10x.
💰
5D Cost Estimator
Select any element in the INSPECT panel. Set Unit Cost and Quantity. The calculated cost and running project grand total update live.
👁️
Visibility Controls
Use Show All / Hide All in the toolbar. Select an element then use Isolate to view it alone or Hide to remove it from scene.
📷
Quick View Toolbar
FIT fits all geometry in frame. TOP switches to 2D orthographic floor plan. ISO restores 3D perspective orbit view.
🧭
ViewCube & Compass
The NavCube in the top-right corner snaps camera to any face. The compass ring shows cardinal directions N E S W around the cube.
🎨
Theme & Post-Processing Engine
Select from 9 architectural themes (Zen, Cyberpunk, Pencil, Blueprint, etc.) in the header. Customize Bloom, Vignette, Chromatic Aberration, and GLSL Shader FX overlays in key 4 SCENE panel.

CAMERA MODES
🌐 Orbit Mode
Default mode. Left-click drag to orbit around a pivot point. Scroll to zoom. Right-click drag to pan. Best for inspecting models from all angles.
Activate: Key 4 Navigation Mode Orbit
🚶 First Person Mode
Walk through the building as if you were inside it. Use W A S D to move, mouse to look around. Stair-climbing is simulated on elevation changes.
Activate: Key 6 Camera First Person
📐 Top Plan Mode
2D orthographic view locked top-down. Ideal for reviewing floor plans, measuring distances, and checking room layouts without perspective distortion.
Activate: Quick View TOP button
TIPS & BEST PRACTICES
💡Use Isolate to focus on a single element type, then use the Tape Measure for clean dimensions without clutter.
💡Switch to TOP Plan view before placing Section Cuts -- easier to align cutting planes on a 2D grid.
💡In 4D mode, set playback to 10x for a fast overview, then slow to 1x to inspect specific construction phases.
💡Export your model to .frag format for fast reloads -- FRAG files load significantly faster than raw IFC files.
💡Press ? at any time to reopen this guide. Your 4D/5D data is saved locally in the browser cache.
